# Day 1 Task: Chatbot vs Rule-Based Workflow vs AI Agent

Scenario: A college's private course-fee database contains:
- CS101: Rs. 12,000
- AI202: Rs. 18,000
- DS303: Rs. 15,000

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Create a `.env` file using `.env.example`. Run:

```bash
python chatbot.py
python workflow.py
python agent.py
python challenge.py
```

Save screenshots of the three program outputs inside `Output/`.

Do not upload `.env` or API keys.
