# Course Fees and Late Payment Policy

## Course Fees

| Course Code | Course Name                          | Fee     |
| ----------- | ------------------------------------ | ------- |
| CS101       | Introduction to Computer Science     | ₹12,000 |
| AI202       | Artificial Intelligence Fundamentals | ₹18,000 |

## Late Payment Fee

The late payment fee is ₹100 per day.

The maximum late payment fee is ₹2,000.

For calculations, the applicable late payment fee is:

The number of days late multiplied by ₹100, capped at ₹2,000.

Examples:

- 5 days late: ₹500.
- 10 days late: ₹1,000.
- 20 days late: ₹2,000.
- 30 days late: ₹2,000 because the maximum has been reached.

These examples are arithmetic examples and must not be presented as a different institutional policy.

## Required Combined Calculation

The total of the CS101 fee, AI202 fee, and maximum late payment fee is:

₹12,000 + ₹18,000 + ₹2,000 = ₹32,000.

If the late payment is instead 5 days, the total becomes:

₹12,000 + ₹18,000 + ₹500 = ₹30,500.

The agent should use the calculator tool to calculate totals where appropriate.
