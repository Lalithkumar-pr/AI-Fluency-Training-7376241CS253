# AI Fluency Training Notes

## Retrieval-Augmented Generation

Retrieval-Augmented Generation, or RAG, retrieves relevant information from a knowledge base and uses it to ground a language model's response.

## Embeddings

Embeddings represent text as numerical vectors that can be compared to identify semantic similarity.

## Vector Databases

Vector databases store vectors and associated data to support similarity-based retrieval.

## Agents and Tools

An agent can select tools to perform tasks such as searching documents, checking eligibility, or calculating a result.

## Memory

Conversational memory allows an agent to retain relevant context across turns. The behavior depends on the selected checkpointing or persistence mechanism.

## Guardrails

Guardrails restrict unsupported or unsafe behavior. A retrieval relevance guard can prevent an agent from answering from unrelated documents.
